АВТО КОНТЕЙНЕРЫ — ИСПРАВЛЕННАЯ ВЕРСИЯ

1) Если просто открыть static/index.html на телефоне/ПК:
   запускается автономный ДЕМО-РЕЖИМ.
   Баланс 100 000 ₽, контейнеры, прокрутка, машины, гараж,
   продажа, уровень/XP и переводы в демо-режиме работают без сервера.
   Демо-перевод: @alex / @ivan / @max.
   Прогресс сохраняется в localStorage.

2) Для НАСТОЯЩЕЙ игры в Telegram:
   нужен сервер с HTTPS.
   Скопируй .env.example -> .env
   BOT_TOKEN=токен от BotFather
   WEBAPP_URL=https://твой-домен/

   Затем:
   pip install -r requirements.txt
   uvicorn app:app --host 0.0.0.0 --port 8000
   В отдельном терминале:
   python bot.py

   Telegram Mini App передает серверу initData. Сервер проверяет ее
   перед изменением баланса, открытием контейнера, продажей и переводом.

3) Важно:
   Реальный перевод между ДВУМЯ Telegram-пользователями возможен
   только в серверном режиме. Обычный HTML-файл не может изменить
   баланс другого телефона.
